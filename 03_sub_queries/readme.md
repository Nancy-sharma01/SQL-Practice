# Day 08 – SQL Subqueries

## 📌 Topic: Subqueries

Today I learned about **Subqueries in SQL** and practiced using queries inside other queries to make SQL statements more dynamic and efficient.

A **subquery** is a query written inside another SQL query. It can be used to retrieve a value or set of values that are required by the outer query.

---

## 🧠 What I Learned

### 1. Finding the Average Marks

First, I calculated the average marks of all students:

```sql
SELECT AVG(marks)
FROM student;
```

**Result:** `84.5000`

Then I used the average value to find students who scored above average:

```sql
SELECT name, marks
FROM student
WHERE marks > 84.5000;
```

However, using a fixed value is not ideal because the average may change when the data changes.

### 2. Using a Subquery to Find Students Above Average

Instead of manually providing the average marks, I used a subquery:

```sql
SELECT name, marks
FROM student
WHERE marks > (
    SELECT AVG(marks)
    FROM student
);
```

Here, the inner query calculates the average marks, and the outer query finds students whose marks are greater than that average.

---

### 3. Finding Even Roll Numbers

I practiced finding students with even roll numbers using the modulo operator:

```sql
SELECT roll_no
FROM student
WHERE roll_no % 2 = 0;
```

Then I used `IN` with specific roll numbers:

```sql
SELECT name, roll_no
FROM student
WHERE roll_no IN (102, 104, 106);
```

Finally, I replaced the fixed values with a subquery:

```sql
SELECT name, roll_no
FROM student
WHERE roll_no IN (
    SELECT roll_no
    FROM student
    WHERE roll_no % 2 = 0
);
```

This approach is more dynamic because the values are generated by the subquery instead of being manually entered.

---

### 4. Subquery in the `FROM` Clause

I also practiced using a subquery as a temporary table.

First, I found students from Delhi:

```sql
SELECT *
FROM student
WHERE city = 'Delhi';
```

Then I used that result as a temporary table to find their maximum marks:

```sql
SELECT MAX(marks)
FROM (
    SELECT *
    FROM student
    WHERE city = 'Delhi'
) AS temp;
```

The subquery inside the `FROM` clause creates a temporary result set named `temp`, which can then be used by the outer query.
